# 早テイクバック Rally v4.2

ジュニアテニス向けの、相手の準備動作とインパクトを見て早くテイクバックするためのPWAです。

## v4.2変更点
- カメラ判定を削除
- 手動のOK / 遅れ判定を削除
- スコア / コンボ / 成功率を削除
- 相手が動いて打つアニメーションは継続
- ボールの左右 / 前後をランダム表示
- 時間 / 球数 / レベル / モードだけを記録
- 自動で次の球へ進むため、ラケットを持ったまま練習できる

## 狙い
評価することよりも、相手の打点で準備を始める反応習慣を作ることに特化しています。
