# 早テイクバック

ジュニアテニス向けの「相手のインパクトを見て、フォア／バックのテイクバックを早くする」iPhone用PWAです。

## 主な機能
- フォア／バックのランダム配球
- フォア／バック＋前後の判断
- 右利き／左利き対応
- 30/45/60/90秒セット
- 4段階のテンポ
- 保護者・コーチによる「OK／遅れ」判定
- 4種類の実写動画をiPhoneから登録（IndexedDBに端末保存）
- 動画未登録でもアニメーションで練習可能
- オフライン対応（PWA）

## iPhoneで使う一番簡単な方法
1. このフォルダをWebサーバーまたはGitHub Pagesに置く。
2. iPhoneのSafariでURLを開く。
3. 共有ボタン →「ホーム画面に追加」。
4. 以後は通常のアプリのように起動可能。

## 実写動画の撮り方
対戦相手役をベースライン付近から正面撮影し、インパクト前0.3〜0.5秒〜インパクト後0.5〜1秒程度に切った短い動画を使うと、予測練習に向きます。

登録枠：
- 相手フォア → 自分フォア
- 相手フォア → 自分バック
- 相手バック → 自分フォア
- 相手バック → 自分バック
