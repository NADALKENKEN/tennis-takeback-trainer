# 早テイクバック GAME v3

小学生ジュニアテニス向けの、矢印反応型テイクバック練習PWAです。

## コンセプト
人型アニメーションや簡易コートは使わず、iPhone中央を見て待ち、矢印が出た瞬間にスプリットからフォア／バックの準備へ入ることに集中します。

## v3の主な機能
- 大きな矢印によるフォア／バック反応
- 4方向（フォア前・フォア後ろ・バック前・バック後ろ）
- サバイバルモード（時間経過で高速化）
- レベル1〜5
- 30 / 45 / 60 / 90秒
- 右利き／左利き対応
- フォアとバックを色分け
- 保護者による「OK／遅れ」判定
- スコア、コンボ、ベストコンボ、ランク
- 端末内に直近記録を保存
- 効果音・バイブレーション
- オフライン利用できるPWA

## 推奨練習
最初は「左右」「Lv.2〜3」「30秒」「保護者採点」で開始。
成功率85%以上を3セット程度安定して取れたら、レベルを1段階上げるか4方向へ進みます。
