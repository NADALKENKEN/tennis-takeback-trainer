# 早テイクバック Reaction v4

ジュニアテニス向けの、相手の動きとインパクトを見て準備するPWAです。

## v4の主な追加点
- 相手が動いて打つアニメーションを復活
- ボールの左右 / 前後を表示
- 前面カメラによる自動反応時間計測
- 平均反応時間 / 最速反応時間 / 計測回数を表示
- 保護者採点 + 自動計測の併用
- スコア、コンボ、履歴保存
- GitHub Pagesでそのまま使えるPWA

## 使い方
1. iPhoneを目線の高さに固定
2. 前面カメラに上半身〜全身が入る位置へ立つ
3. 相手の準備動作 → インパクトを見る
4. インパクト直後にスプリットとテイクバック
5. 保護者はOK / 遅れを押す（または自動判定）

## 自動計測について
簡易モーション検知により、インパクトからプレイヤーが動き始めるまでの時間を計測します。
背景が大きく動く場所、暗い場所、カメラに身体が十分映っていない場合は精度が下がります。
